# Centwise Features

Centwise is a Bangladesh-focused SMS expense tracker for Android and iOS.

## Transaction Tracking

- Automatic transaction creation from bank SMS
- Automatic transaction creation from MFS SMS
- Android real-time SMS processing
- iOS Shortcuts Message Automation processing
- iOS SMS Share Extension fallback
- Manual transaction entry
- Edit transactions
- Delete transactions
- Income transactions
- Expense transactions
- Transfers
- Refunds and reversals
- Transaction date and time
- Amount and currency
- Merchant or counterparty
- Bank, MFS service, account, and card information
- Account last four digits
- Transaction reference or ID
- Balance after transaction when present in the SMS
- Transaction notes
- Transaction attachments in a later version

## Bangladesh Support

- Bangladeshi bank SMS formats
- bKash SMS
- Nagad SMS
- Rocket SMS
- Bank card SMS
- ATM withdrawal SMS
- Bank transfer SMS
- Mobile recharge SMS
- Payment and merchant SMS
- English-language SMS handling
- Bangladeshi taka formatting and ৳ currency support
- Local sender-ID detection
- Unsupported SMS review queue
